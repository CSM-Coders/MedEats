# Nota: Desarrollo local y pruebas de API

Este archivo apunta a `docs/DEVELOPMENT_AND_RUN.md` para instrucciones detalladas de arranque y pruebas locales.

Resumen rápido:

- Para arrancar todo (backend + mobile):

```bash
cd /path/to/MedEats
nvm use
npm run dev
```

- Para arrancar solo backend:

```bash
npm run dev:backend
```

- Para arrancar solo mobile:

```bash
npm run dev:mobile
```

Consulta `docs/DEVELOPMENT_AND_RUN.md` para más detalles y troubleshooting.
